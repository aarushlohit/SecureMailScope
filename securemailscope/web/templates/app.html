Help & Protocol Rules

Reference for deterministic protocol engines and evidence gates.

SecureMailScope evaluates passive network captures (SMTP, IMAP, POP3) under SIH26159 (NTRO). All conclusions require empirical proof registered in the Evidence Ledger.

Active Cryptographic Rules:
  • RULE-STARTTLS-PLAINTEXT-VIOLATION • Flags cleartext continuation post-STARTTLS.
  • RULE-CIPHER-BROKEN • Flags RC4 and weak stream ciphers.
  • RULE-TLS-DEPRECATED • Flags deprecated TLS 1.0 / 1.1 handshakes.
  • RULE-NO-PFS • Flags static RSA without Forward Secrecy.
  • RULE-CERT-EXPIRED • Validates X.509 temporal validity against UTC clock.
